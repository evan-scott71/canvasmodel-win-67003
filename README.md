## About CanvasModel

CanvasModel is a browser-based tool for preparing a business model canvas and producing a corresponding canvas report. It provides a focused way to organize business model information in one place before reviewing or sharing the resulting document.

The project is suited to founders, teams, students, consultants, and anyone who needs a structured business model canvas workflow. Its main purpose is report generation, making the transition from canvas input to a readable report more direct.
